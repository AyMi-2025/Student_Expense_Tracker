# 🚀 Free Deployment Guide for CampusSpend

You can deploy CampusSpend in **less than 60 seconds** for **100% free** using any of the following methods:

---

## ⚡ Option 1: Netlify Drop (Fastest — 10 Seconds, No Account Needed)

1. Open your browser and go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Open File Explorer on your laptop and go to:
   ```
   C:\Users\Ayan Maiti\.gemini\antigravity\scratch\student-expense-tracker\standalone
   ```
3. Drag and drop the `standalone` folder (which contains `index.html`) directly into the Netlify Drop box on the webpage.
4. 🎉 **Done!** Netlify will immediately give you a live HTTPS link (e.g., `https://peaceful-campus-1234.netlify.app`).
5. Open that link on your phone, laptop, or share it with college friends!

---

## 🐙 Option 2: GitHub Pages (Permanent Free URL)

1. Go to [GitHub.com](https://github.com) and click **New Repository** (e.g., name it `campus-expense-tracker`).
2. Set the repository to **Public** and create it.
3. Click **"uploading an existing file"** and upload the `index.html` file from:
   ```
   C:\Users\Ayan Maiti\.gemini\antigravity\scratch\student-expense-tracker\index.html
   ```
4. Commit the changes.
5. In your GitHub repository, go to **Settings** &rarr; **Pages** (in the left sidebar).
6. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
7. In about 30 seconds, your site will be live at:
   ```
   https://<your-github-username>.github.io/campus-expense-tracker/
   ```

---

## ▲ Option 3: Vercel

1. Push or upload your code to GitHub.
2. Go to [Vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New Project"** and import your repository.
4. Leave all build settings default (zero configuration needed).
5. Click **"Deploy"**.
6. You will get a live link like `https://campus-expense-tracker.vercel.app`!

---

## 📱 Using as a Mobile App on iPhone & Android

Once your site is live on Netlify, GitHub Pages, or Vercel:

### On iPhone (Safari):
1. Open your live URL in Safari.
2. Tap the **Share** button (box with an arrow pointing up at the bottom).
3. Scroll down and tap **"Add to Home Screen"**.
4. Tap **Add**. The app will appear on your iPhone home screen with an app icon and will open full-screen without address bars!

### On Android (Chrome):
1. Open your live URL in Google Chrome.
2. Tap the three dots menu (top right).
3. Tap **"Install app"** or **"Add to Home Screen"**.
4. It will now launch directly from your home screen like a native mobile app!
