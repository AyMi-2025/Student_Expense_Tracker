How to Deploy This HTML File Free

This entire application is completely self-contained in this single index.html file! You can deploy it in 30 seconds:

Option 1: Netlify Drop (Zero Setup, 10 Seconds) Recommended
  1. Go to app.netlify.com/drop
  2. Drag & drop the folder containing this index.html into the box.
  3. Netlify will give you an instant live URL (e.g. https://campusexpenses.netlify.app) that you can open on any phone or laptop in the world!
Option 2: GitHub Pages (Permanent Free Hosting)
  1. Create a new repository on GitHub.com (e.g. student-expenses).
  2. Upload this index.html file to the root of the repository.
  3. Go to Settings → Pages → Branch: main → Save.
  4. Your site goes live at https://yourusername.github.io/student-expenses/!
Option 3: Vercel

Import your GitHub repo into Vercel.com and click Deploy with zero build settings!
